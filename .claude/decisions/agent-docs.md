# Документация агента

## Раскладка `.claude/`

Длинный файл, прочитанный в начале сессии, к моменту ошибки забыт. Поэтому: короткий корень с ограничениями и маршрутом, `rules/` по областям, тематические `decisions/` и `pitfalls/`, справка `docs/systems/`, открытый остаток `docs/debts.md`, план вех.

- **Нет `.codex/` и `AGENTS.md`** — над проектом работает один агент.
- **Нет HTML-сайта** — справка для человека и агента одна, `docs/systems/`.
- **Нет git** — закрытые планы и выгрузки уходят в `backup/` копией.
- **`paths` почти не работает.** Код живёт в Studio, файлов на диске нет, и frontmatter `paths` срабатывает только на локальных документах. Поэтому `workflow` и `code-style` — правила **без** `paths` (Claude Code грузит такие всегда), остальные читаются явно по таблице корня.
- **Главный триггер граблей — хук на инструмент MCP** ([памятки](../hooks/roblox-mcp-reminders.json)): привязать напоминание к пути файла не к чему.

Цена: правила без `paths` занимают контекст каждой сессии, поэтому их двое и они короткие. Пересмотр — если появится Rojo и код ляжет на диск: тогда правила областей получают `paths` на файлы кода.

## Навык workflow не заводится

Регламент — правило без `paths`, которое грузится само: навык надо не забыть вызвать, правило — нет.

## Планирование с пользователем обязательно

Регламент ([workflow](../rules/workflow.md), раздел «Рабочий процесс» корня) запрещает агенту решать за пользователя: до согласования — только чтение проекта и Studio. Формулировка «рутинные решения принимай сам» давала агенту выбирать несогласованное.
