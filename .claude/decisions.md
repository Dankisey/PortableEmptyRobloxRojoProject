# Принятые решения

Индекс неочевидных развилок. Перед заменой решения прочитай тематический файл; пересмотр согласуй с пользователем. Требования к правкам — в [rules/](rules/), открытый остаток — в [docs/debts.md](docs/debts.md).

| Файл | Решения |
|---|---|
| [framework.md](decisions/framework.md) | свой DI, без Rojo, инфраструктура вне ядер, счётчики на инстансах и атрибутах, границы модулей |
| [saves.md](decisions/saves.md) | всё сохраняемое — разделы сервисов + атрибуты, ProfileStore, синк, `IsLoaded`, `/wipe`, порядок входа |
| [character-physics.md](decisions/character-physics.md) | физика у клиента, устройство рэгдолла, коллизионные группы кодом |
| [input-and-ui.md](decisions/input-and-ui.md) | тулы без `Activated`, тап в любую точку под флагом, отпускание, `InputBegan` и кнопка удержания, подпись по `PreferredInput`, курсор, первое лицо, ввод мыши |
| [agent-docs.md](decisions/agent-docs.md) | раскладка документации, правила без `paths`, хук вместо навыка, обязательное планирование |

В записях — причина, цена и условие пересмотра. Принятое решение не означает реализованную механику. Игровые решения заводятся отдельными файлами по мере вех.
